## 潮汐演算 1.0

- 支持通用限定角色、限定武器和联合目标，含多份抽取、共鸣链和谐振。
- 逐抽追踪珊瑚回流、商店额度、共享资源及角色重复持有。
- 比较两种固定顺序、逐抽动态策略和关闭新增回流的基线。
- 可调两池概率曲线、四星判定及持有量。结果显示可证明的概率区间。

## 安装

要求 macOS 13 或更新版本。Apple Silicon 下载 `macos-arm64`，Intel 下载 `macos-x64`。解压后将 `TidePlanner.app` 移入「应用程序」。

应用采用临时签名，未经过 Apple 公证。若首次打开被系统拦截，核对来源及 `SHA256SUMS.txt`，再按 Apple 的「仍要打开」指引操作。[Apple 支持](https://support.apple.com/zh-cn/102445)
